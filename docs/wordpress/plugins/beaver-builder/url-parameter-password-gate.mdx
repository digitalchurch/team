# URL Parameter Password Gate (`pw`)

This pattern gives you a quick way to keep a lightweight password value in the URL and carry it across internal page links.

We used this for the ENC LTI event for AMEZion as a simple access layer during event workflows.

:::warning Not a security system
This is a convenience gate, not true authentication. Anyone who has the URL parameter can share it.

Use real auth for long-term or sensitive protection.
:::

## How it works

1. Read `pw` from the current page URL.
2. Store it in `sessionStorage` for that browser tab/session.
3. Rewrite internal links so they keep `?pw=...` as users click around.
4. Skip all behavior while Beaver Builder is in edit mode.

## Beaver Builder-safe version

Paste this in **Beaver Builder → Settings → Global Settings → JavaScript**.

```js
(function () {
  if (typeof window === 'undefined' || typeof document === 'undefined') return;

  function isBeaverBuilderMode() {
    const params = new URLSearchParams(window.location.search);

    // Any Beaver Builder mode/query flag
    for (const key of params.keys()) {
      if (key.startsWith('fl_builder')) return true;
    }

    // Front-end builder global object
    if (typeof window.FLBuilder !== 'undefined') return true;

    return false;
  }

  // Don't run anything while editing in Beaver Builder
  if (isBeaverBuilderMode()) return;

  function getParameterByName(name, url = window.location.href) {
    name = name.replace(/[\[\]]/g, '\\$&');
    const regex = new RegExp('[?&]' + name + '(=([^&#]*)|&|#|$)');
    const results = regex.exec(url);
    if (!results) return null;
    if (!results[2]) return '';
    return decodeURIComponent(results[2].replace(/\+/g, ' '));
  }

  function getStoredPw() {
    try {
      return sessionStorage.getItem('pw');
    } catch (_) {
      return null;
    }
  }

  function setStoredPw(value) {
    try {
      sessionStorage.setItem('pw', value);
    } catch (_) {
      // ignore storage errors
    }
  }

  // Save pw from URL into sessionStorage
  const passwordParam = getParameterByName('pw');
  if (passwordParam) {
    setStoredPw(passwordParam);
  }

  function appendPwToLinks() {
    if (isBeaverBuilderMode()) return;

    const pw = getStoredPw();
    if (!pw) return;

    const links = document.querySelectorAll('a[href]');

    links.forEach((link) => {
      const rawHref = link.getAttribute('href');
      if (!rawHref) return;

      // Skip non-navigational/special links
      if (
        rawHref.startsWith('#') ||
        rawHref.startsWith('mailto:') ||
        rawHref.startsWith('tel:') ||
        rawHref.startsWith('javascript:')
      ) {
        return;
      }

      let url;
      try {
        url = new URL(rawHref, window.location.href);
      } catch (_) {
        return;
      }

      // Internal links only
      if (url.origin !== window.location.origin) return;

      // Avoid touching WP admin/login URLs
      if (
        url.pathname.startsWith('/wp-admin') ||
        url.pathname.startsWith('/wp-login.php')
      ) {
        return;
      }

      url.searchParams.set('pw', pw);
      link.href = url.toString();
    });
  }

  if (document.readyState === 'loading') {
    window.addEventListener('DOMContentLoaded', appendPwToLinks);
  } else {
    appendPwToLinks();
  }
})();
```

## Why this version is safer for Builder use

- It exits early when Beaver Builder is active (`fl_builder*` params or `window.FLBuilder`).
- It only rewrites internal links.
- It skips anchors, mail links, phone links, and JavaScript links.
- It avoids modifying `/wp-admin` and `/wp-login.php` URLs.

## Quick test checklist

1. Open a front-end page with `?pw=test123`.
2. Click to another internal page and confirm `pw` stays in the URL.
3. Open Beaver Builder editor and confirm builder behavior is normal.
4. Clear cache/minification, then hard refresh if old behavior persists.

## Known limitations

- `sessionStorage` is tab/session-specific.
- New tabs opened without `pw` in URL do not inherit it.
- This should not be used as a replacement for WordPress auth, membership plugins, or server-side access control.
