Use this guide to connect Cloudflare Turnstile to Gravity Forms and verify it is working on the front end.

## Prerequisites

- WordPress admin access
- Gravity Forms installed and active
- Gravity Forms Cloudflare Turnstile plugin installed and active
- Cloudflare account access for the target domain

## 1) Create a Turnstile widget in Cloudflare

1. In Cloudflare, go to **Turnstile**.
2. Create a new widget for the site domain.
3. Copy the generated:
   - **Site Key**
   - **Secret Key**
4. Save the widget.

## 2) Add keys in Gravity Forms settings

1. In WordPress, go to **Forms → Settings → Cloudflare Turnstile**.
2. Paste the **Site Key** and **Secret Key** from Cloudflare.
3. Save settings.

## 3) Enable Gravity Forms integration

1. Confirm Turnstile is enabled in Gravity Forms settings.
2. If there is a global toggle for form protection, turn it on.
3. Save settings.

## 4) Add a Turnstile field to each form

1. Open the target form in Gravity Forms.
2. Add the **Turnstile** field (usually near the end of the form).
3. Save/update the form.

## 5) Front-end testing

1. Open the public page containing the form (use an incognito/private window).
2. Confirm Turnstile renders.
3. Submit a valid test entry.
4. Verify submission succeeds.
5. Confirm entry is visible in Gravity Forms entries.

## 6) Troubleshooting

- **Turnstile does not render**: Re-check Site Key, domain in Cloudflare widget, and plugin activation.
- **Validation fails on submit**: Re-check Secret Key, integration toggles, and form field placement.
- **Works when logged in but not for visitors**: Test in incognito and clear site/cache plugin/CDN caches.
- **Intermittent issues**: Check browser console errors and plugin/theme conflicts.
