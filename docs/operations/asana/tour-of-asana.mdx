# Intro to Asana

Take a tour of Asana and Everhour and discover how we use it in Digital Church to manage client projects, product development, support, etc. You can access asana here: [https://app.asana.com/1/862215408362969/home](https://app.asana.com/1/862215408362969/home)

## Tour & Setup

We use Everhour to track time across projects so we can make sure our billing is correct. One project tracks all our "Unlimited Development" clients as an ongoing project. Other projects are usually short-term projects that have a start and end date.
